# このアプリケーションの構成

このリポジトリは、RAG チャットボットを開発するための雛形アプリである。
フロントエンドとバックエンドの2つのサービスを Docker Compose でまとめて起動する。

## フロントエンド

フロントエンドは Angular で実装されており、単一の画面を表示する。
ユーザーが入力欄に質問を入力して送信すると、バックエンドの `/api/chat` を呼び出し、返ってきた回答を画面に表示する。
ビルドした成果物は nginx で配信され、`/api/` へのリクエストはバックエンドにプロキシされる。フロントエンドはブラウザのポート 8080 で公開される。

## バックエンド

バックエンドは NestJS で実装された API サーバーで、ポート 3000 で動作する。
モデル API の呼び出しはバックエンドだけが行い、API キーや接続先などの設定をフロントエンドには置かない。
`POST /api/chat` で質問を受け取り、OpenAI 互換の `chat/completions` を呼び出して回答を返す。

## モデルの接続先

接続先は環境変数で切り替えられる。`OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL` などを設定する。
ローカル検証では LM Studio を使い、本番では OpenAI の API に切り替えることを想定している。
バックエンドは Docker コンテナ内で動くため、ホスト上の LM Studio へは `host.docker.internal` を通じて接続する。

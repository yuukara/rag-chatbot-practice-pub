# LM Studio の利用について

LM Studio はローカル PC 上で LLM の API サーバーを立てられるツールである。
OpenAI 互換のエンドポイントを提供するため、OpenAI 向けに書いたコードを接続先だけ変えてそのまま利用できる。

## このアプリでの利用方法

LM Studio 側で API サーバーを起動し、使用するモデルをロードしておく必要がある。
バックエンドのデフォルトの接続先は `http://host.docker.internal:1234/v1` で、LM Studio の標準ポートは 1234 である。

## 利用するモデル

このアプリではチャット用と埋め込み用の2種類のモデルを使う。
チャット用モデルには `openai/gpt-oss-20b` を使用している。
埋め込み用モデルには `text-embedding-bge-m3` を使用しており、これが生成するベクトルの次元数は 1024 である。

## LM Studio を使う利点

OpenAI API の課金なしで試せること、オフライン寄りの検証ができること、OpenAI 互換 API なのでフロントとバックの配線を先に作りやすいことが利点である。
一方でモデルの品質や応答速度、日本語性能は利用するモデルに依存する点に注意が必要である。
